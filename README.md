## 🚀 Featured Projects

### 🩺 Pneumonia Detection from X-ray Images using CNN  
Developed a CNN-based medical image classification model for pneumonia detection from chest X-ray images.  
Used data augmentation, early stopping and explainable AI techniques such as Grad-CAM.  
**Technologies:** TensorFlow, Python, OpenCV, Scikit-learn, Google Colab  

### 🧠 Multimodal Fusion for Offensive Content Detection  
Developed a multimodal learning system combining text and image data for offensive content detection.  
Compared single-modality and multimodal model performances.  
**Technologies:** VGG16, CNN, BiLSTM, GloVe, ASP.NET Core Web API, Angular, MSSQL  

### 📡 Smart Spectrum Recommendation for 5G and Beyond  
Conducted AI/ML-based research on spectrum recommendation and numerology allocation for 5G & Beyond radio planning.  
Worked with simulated radio scenarios and validated models using statistical methods.  
**Technologies:** Python, MATLAB, Machine Learning, Wireless Communications  

### 🌬️ ESP32-Based Anemometer System  
Designed an ESP32-based system to monitor wind speed, temperature and humidity, and transmit real-time data to a web application.  
**Technologies:** ESP32, HMC5883L, IR Sensor, I2C, Web Server  

### 🏭 NodeMCU-Based Factory Automation  
Developed an IoT telemetry system using NodeMCU and sensor data transmission over Wi-Fi.  
Implemented stable real-time communication and persistent storage.  
**Technologies:** ESP8266, DHT11, SOAP API, AutoConnect, LCD  

### 🔋 STM32-Based Li-Ion Battery Management System  
Designed a battery monitoring system using ADC-based voltage measurement, LCD interface and MOSFET-based power optimization.  
**Technologies:** STM32F103, MOSFET, LCD, Li-Ion Battery
